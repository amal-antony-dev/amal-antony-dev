### Featured work

**[Crisis-Graph](https://github.com/amal-antony-dev/crisis-graph)**: flood emergency dispatch where the LLM extracts and deterministic code decides.
Rust services turn multilingual SOS messages (English, Malayalam, Manglish) into verified vehicle dispatches. A fine-tuned Qwen3-4B only proposes a candidate report; routing, allocation and per-segment verification make every decision, and anything uncertain goes to a person.

- **40 → 81** exact extractions on 120 blind cases after QLoRA fine-tuning
- **20 reports/s** surge with every report accepted and 0 unverified routes
- **12 → 39/min** T4 throughput after fixing a grammar bottleneck, identical answers
